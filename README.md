# lucia-murillo.github.io

## General information 
This repository is for my ENVS 193DS optional website project. This repo is mine (Github username: lucia-murillo). 

## Data and file information 
There are four folders. First, an `extensions` folder, which contains the extensions used in this project. Next, the `docs` folder, which contains the html information.It also has an `images` folder, which has the images that were used in the website. Last, the `posts` folder, which has two sub-directories, `envs40`, and `midterm`, which are the blog posts. The `.qmd` files are pages within the website. The `styles.scss` file contains the stylistic information such as colors and fonts for the website.
